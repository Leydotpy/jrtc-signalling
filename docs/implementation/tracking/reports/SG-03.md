## Behavior and files

`services/gateway_tickets.py` issues RS256 tickets from existing authenticated
profiles and Django admission state. Pending non-member guests get lobby only;
anonymous identity is not an existing backend facility and remains denied.
`api/gateway.py` adds bounded authenticated HTTPS endpoints, no-store responses,
correlation IDs, exact request fields and a dedicated service-authority token.
Migration 0014 adds the participant epoch, current connection grant and shared
one-use ticket receipt. No credential is persisted in the receipt. The bounded
pruning management command removes expired receipts without enabling replay.

`services/lifecycle.py` advances epochs transactionally for admission, denial,
permission changes, removal, leave and meeting end. Issuance/consumption share
meeting row locks with these transitions. A new connection/resume generation
fences old tickets; refresh binds to the existing identity/generation. Durable
issuance limits survive process restart. Effective media permissions are returned
by the service lookup; live cache invalidation is SG-04/06 work.

`docs/gateway-control-plane.md` records configuration, key rotation, guest scope,
HTTP contracts, storage retention and rollback. The feature defaults off. No
Janus calls or existing runtime ownership were changed.
