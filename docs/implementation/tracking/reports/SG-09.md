## Contract and security decisions

One candidate remains a plural SDK array; a final three-candidate batch is sent
intact, then completion. Empty completion sends only completion. Duplicate empty
completion is a no-op after confirmation; candidates after completion reject.
The connection's ordered worker and peer/owner locks prevent interleaving. The
combined batch/completion call has a three-second deadline, further limited by
lease expiry. Timeouts/errors/cancellation do not produce automatic retries.

Candidates must match an active negotiated MID/index. If supplied, browser
`usernameFragment` and candidate-line `ufrag` must match actual SDP credentials;
the unsupported SDK field is stripped only after this check. Legacy candidates
without either fragment remain accepted under the current authenticated connection,
negotiation ID and MID/index. Their omission cannot attest which browser gathering
generation produced them; the SG-12 adapter must preserve candidate-generation
binding rather than relabel delayed candidates with a new ID.

Restart requires fresh browser username fragment **and** password; changing only
a wire UUID does not reset the ICE state. Pending restarts block trickle. Same-ICE
renegotiation retains completion and budgets. Retired credential sets cannot be
revived. Publisher restart reserves an ID for its next offer; subscriber restart
asks Janus for an offer and awaits the matching answer. Unsolicited subscriber
restart offers remain processable; old correlated callbacks are suppressed and
stale credentials cannot become the current negotiation. Janus IDs remain integers
internally and canonical decimal strings at the browser boundary.

Bounds: 32 candidates / 64 KiB per payload; 256 forwarded candidates / 256 KiB per
ICE generation; 64 publisher negotiation IDs per connection and 64 subscriber
offers per handle. Existing bounded request/reply/event queues, exact replay and
SDK/session/owner fences remain in effect. No SDP, ICE or credentials go to Broka,
Django authority payloads or application logs. The gateway never transports RTP.

Sensitive transitions retain SG-04's fresh authority preflight; trickle may use
the existing 0.5-second grant cache. Checks between the two Janus sends enforce
the locally known revision/ownership, not a new atomic distributed authorization
transaction. Production command enforcement and revocation remain SG-13.
