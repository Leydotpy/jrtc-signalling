## Implementation and contracts

Synq `src/apps/meetings/models.py:862` and migration 0016 add dispatch leases,
retry state, immutable commands, authenticated outcome receipts, quarantine,
meeting epochs and an owner-route publication boundary. Existing transactional
admit, deny, disconnect and permission intents now dispatch; `services/
gateway_outbox.py:78` adds one idempotent meeting.terminate intent in the meeting
end transaction. The five command payloads validate against the gateway schemas.

`services/gateway_commands.py:92` locks/leases the intent and rechecks current
permission, epoch, participant binding and owner route before publication.
Attempts preserve the command ID, payload, owner/generation and deadline.
`services/gateway_dispatcher.py:36` publishes outside database transactions using
the configured Broka Redis Streams backend. Publication timeout or lost ACK
retains the committed request for retry. Limits are ten attempts, ten-second
dispatch leases, backoff capped at 30 seconds, command TTL at most 60 seconds and
intent age at most 300 seconds. Terminal rows retain dead-letter evidence.
No-owner requests back off and fail explicitly; an owner/binding change never
silently retargets an uncertain command.

`api/gateway.py:209` exposes the service-authenticated current-command authority
check; `:224` exposes enforcement status to the subject or a current moderator.
`services/gateway_commands.py:284` verifies outcome correlation and deduplicates
receipts under the meeting lock. Stale events cannot restore revoked permission,
turn accepted into applied, reverse terminal results or mark media connected.

Gateway `src/jrtc_signalling/bus.py:69` signs bounded canonical JSON with Ed25519.
Trusted keys pin producer identity; version, key ID, kind and all body fields are
signed. Strict typed validation rejects duplicate/unknown fields, altered owner,
epoch, payload or signature. Only command/outcome schemas are carried. No SDP,
ICE, arbitrary object deserialization, Django ORM or Django settings enter the
gateway. Redis ACL/TLS credentials and bus keys are separate from browser tickets.

`bus_transport.py:22` uses Broka's RedisEngine transport SPI with explicit ACK,
durable consumer groups, pending reclaim and bounded serial consumption. The
adapter accounts for Broka 0.0.2 engine-level group IDs and startup-task failures.
The frozen bus extra corrects upstream wheel metadata that otherwise makes
Django and unrelated engines mandatory; only the reviewed Redis path is used.

`command_store.py:43` stores a persistent SQLite inbox and outcome outbox with
synchronous FULL transactions. Reservation and accepted outcome commit before
execution; terminal outcome commits before broker ACK. Conflicting IDs are
quarantined. Matching duplicates replay stable outcome IDs without executing
again, including after restart. Crash/cancellation after reservation produces an
uncertain timed-out result requiring reconciliation, never automatic re-execution.
Capacity, quarantine, retries and retention are bounded; pending/dead outcomes
are retained. No unsafe approximate stream trimming is enabled.

`commands.py:76` checks signature, owner, TTL, current Django authority and a
bounded enforcer call. `:148` owns broker supervision/outcome relay during ASGI
lifespan; SQLite calls run off the event loop. No Janus reader waits on broker or
storage work. The default `NoOwnerEnforcer` returns failed/owner_lost. SG-07 must
provide the real lease/generation fence at mutation time; no configured identity
or test route is represented as production runtime ownership.

## Limits, follow-up and rollback

SG-07 owns exclusive JRTC sessions/handles, route leases and mutation fencing;
SG-08 owns media dispatch. Lifecycle event production/projection and browser
routing remain later tasks. No live Janus, browser/TURN, ICE latency improvement
or production persistence/failover is claimed by this command-plane task.
Existing ICE paths and legacy runtime ownership remain unchanged.

Before staging, configure protected bus/authority keys, Redis ACLs/TLS,
persistence/no-eviction storage, persistent gateway inbox storage and operational
acknowledged-history compaction. These are documented deployment prerequisites,
not configured production services. See `docs/COMMAND_PLANE.md` and Synq's
`docs/gateway-control-plane.md` for configuration, limits and retention.

Rollback disables new command/admission routing and bus configuration while
preserving committed outbox/inbox/leases, additive migrations and keys for
reconciliation. It does not restore revoked permissions. Uncertain mutations
must be reconciled before any new command ID is issued. The legacy path remains
available; media readiness stays 503. SG-07 is the next task.
