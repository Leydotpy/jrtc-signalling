## Implementation

- auth.py validates bounded duplicate-free JWTs, pinned RSA keys/RS256, issuer,
  audience, required claims and expiry. It provides authenticated HTTPS authority
  lookup, no redirects, bounded responses/timeouts, and a single bounded cached
  grant per connection with revocation-versus-RPC fencing.
- websocket_auth.py enforces WSS, exact Origin/subprotocol, first-frame auth,
  binding/sequence, shared Django replay consumption, refresh identity/epoch,
  lobby/media scopes, track permissions, connection/frame/rate/time budgets and
  safe close reasons. Refresh cannot restore authority invalidated during its RPC.
- app.py owns authentication resources in its lifespan. CLI TLS files and auth
  config are validated without echoing secrets. The default stays disabled;
  configured authentication returns an empty control acknowledgement, never a
  fabricated owner/lease. All media calls remain unavailable and readiness 503.
- AUTHENTICATION.md documents trust/key setup, TLS, limits, refresh, bounded cache
  semantics and rollback. Future SG-06/07/08 must supply revocation delivery,
  exclusive ownership and actual SDP/Janus enforcement before media is enabled.
