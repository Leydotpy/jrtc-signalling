## Implementation

`src/jrtc_signalling/schema_definitions.py` defines nine JSON Schema 2020-12
contracts: request, response, notification, command, event, command outcome,
ticket claims/header and state notification. `scripts/export_schemas.py` exports
portable files included in wheels. `contracts.py` bounds UTF-8 messages, rejects
duplicate keys/non-finite JSON/malformed payloads, enforces validity windows and
projection increments, and exposes input-free errors.

`docs/PROTOCOL.md` maps current Socket.IO events/MeetingConnection methods,
MediaSignalAck/selected-stream fields, Janus correlated/unsolicited JSEP and
existing state enums. It retains combined final ICE batches, explicit completion,
and decimal-string IDs. Negotiation/session/owner generations are distinguished.
`docs/SECURITY.md` defines RS256 ticket/grant requirements. ADR 0001 chooses the
standalone deployment, at-least-once Broka delivery and unchanged legacy fallback.

SSE is a proposed invalidation/reconciliation boundary over the existing Django
state snapshot and client store. No new frontend state model is implemented.
Broker payloads allow only typed data and cannot carry arbitrary SDP/ICE/tickets.
