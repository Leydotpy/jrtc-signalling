## Implementation and contract decisions

Gateway `src/jrtc_signalling/janus_runtime.py:258` owns the generic
JanusSessionManager, bounded event publisher, per-meeting management services,
opaque handle registry and command runtime under ASGI lifespan. Configuration is
explicit and opt-in; no Django models/settings or legacy global manager enter the
gateway. Health reports Janus, broker, authority and ownership separately.
Overall readiness stays 503 because browser media dispatch is not implemented.

`janus_runtime.py:133` serializes attachment, invocation and disposal per meeting.
An opaque handle binds meeting, participant, participant session, role, owner,
generation and the actual SDK session/plugin identity. Concurrent identical
attachments share one binding. Forged, stale, expired or replaced bindings fail;
an uncertain operation invalidates its token and is never automatically replayed.
Internal Janus IDs remain strict positive integers; wire IDs are decimal strings.
The management adapter caches VideoRoomService per live session/generation.

`janus_runtime.py:285` installs the SDK's separate removable loss observer; the
manager retains its own loss handler and recovery responsibility. Reconciliation
invalidates old bindings and services without starting a competing recovery loop.
After server recovery, explicit operations acquire fresh handles and tokens.
Only fixed-field webrtcup/detached/timeout observations enter the bounded generic
publisher. Plugin payloads, SDP/JSEP, ICE, reason text and arbitrary extras are
excluded. This diagnostic sink is not the later durable domain event plane.

`src/jrtc_signalling/ownership.py:62` calls Synq over HTTPS with service bearer
authentication and a canonical Ed25519-signed owner-request. Requests bind the
meeting, process incarnation, action, expected generation, request ID and time.
The client bounds response size, checks correlation and calculates its deadline
from before the request with a one-second reserve. Every operation checks the
current owner/generation, lease, event loop and actual session identity. Mutations
have a three-second budget bounded further by remaining lease time.

Synq `src/apps/meetings/services/gateway_ownership.py:49` locks the meeting row and
publishes the exclusive route in GatewayCommandRoute. Migration 0017 adds the
persisted cohort, process incarnation, release state and retired-incarnation
history. Claim retry preserves the original deadline. Renew/release require the
exact incumbent; a clean later incarnation increments the generation. Old signed
claims cannot revive retired incarnations. Expired but unreleased ownership is
not proof of remote cleanup and cannot be taken over automatically.

Synq `models.py:460`, lifecycle session creation and the legacy Janus/signalling/
Celery entrypoints enforce the persisted cohort. Only new opted-in sessions enter
the gateway path. A gateway host is admitted without media presence or legacy
provisioning. Disabling rollout flags never converts a running gateway session
back to legacy. Exact-owner release remains possible with flags disabled.
The [deferred-path manifest](../../../RUNTIME_OWNERSHIP.md#legacy-path-manifest)
records the ASGI/Celery/browser paths retained for legacy cohorts.

Shutdown drains commands, closes handles and management services before sessions,
removes observers, stops the manager, drains the publisher and releases the exact
lease. Cancellation shares shielded cleanup. Cleanup failure continues through
remaining resources but withholds successful ownership release. Renewal failure
closes access and disposes resources. No automatic reclaim bypasses this fence.

SG-06 dispatchers now discover the actual owner/generation in the durable route.
A stale route fails owner_lost. A valid routed command still fails unavailable
until its physical action is implemented in SG-13; no lease or accepted command
is reported as applied enforcement or connected media.
