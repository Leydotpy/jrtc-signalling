## Implementation and contract evidence

- synq.js `packages/client/src/gateway/wire.ts:66`: WSS, hello/refresh tickets only
  in payloads, strict scoped/generation-fenced messages, safe counters, bounded
  queues/frames, serialized ACKs and terminal handling of ambiguous outcomes.
- `gateway/state.ts:281`: bounded UTF-8 SSE parser, Last-Event-ID, versioned/paginated
  snapshots, 409 restart, stale-event dedupe, quiet gap/reconnect repair, credential
  expiry and abort cleanup.
- `gateway/connection.ts:47`: existing MeetingConnection API over Django HTTPS for
  authority/application state and gateway WS for media only. Admission remains
  separate from connected; lobby grants rotate before media ownership. Actual ICE
  credentials bind each negotiation; trickle waits for matching publish/start ACK.
  Stable domain events preserve live/replay/snapshot sound semantics.
- `StreamVideoClient.ts`, `Call.ts`, `rtc/*`: immutable selection per cached Call,
  no competing Socket.IO connection for gateway meetings, existing legacy path,
  single JSEP processing, real peer connection status and optional TURN relay mode.
- App `gatewayConfig.ts`, `server/meetingProxy.ts`, `server/meetings.ts` and the
  meetings catch-all route: explicit public build-time cohort, SSE passthrough,
  cursor/cancellation forwarding, no-store and existing JSON behavior.
- Synq `services/gateway_sdk.py` and `gateway_state.py`: optional SDK-compatible
  snapshot from one committed projection version, bounded application history,
  current-audience filtering, no legacy media handles or private topology.
- Synq `api/gateway_application.py`: HTTPS, CSRF/authentication, feature/cohort,
  authority and body-size checks for chat, reactions and leave. Admission notes
  and review reasons retain public SDK semantics and bind idempotent decisions.
- Synq `gateway_events.py`: canonical presence events require actual ordered
  media observations; approval does not set connected or joined_at.
- Synq `api/gateway_state.py`: browser SSE Accept negotiation permits the stream
  while authentication/validation failures remain JSON. Actual browser CI found
  the earlier 406; a regression now uses the exact browser request header.

Subscription corrections: `src/jrtc_signalling/auth.py:252` exposes a bounded
pending-check barrier. `media.py:148` waits without another peer's media lock before diffing
topology, so a temporarily cleared grant cannot trigger an unintended unsubscribe.
Settled denial still excludes the source; timeout fails closed. jrtc-video models
explicitly inactive source-less slots while retaining strict feed IDs for active
audio/video. Gateway layouts emit null identity for those inactive slots. The response schema
now also permits null source MIDs. The live publisher-departure regression
at `tests/test_janus_live.py:244`, with plugin `jrtc-video/src/jrtc_video/models.py:704`,
reproduced the earlier host disconnect and now verifies the inactive offer/answer
plus continued host publisher/signalling.
