## Implementation and behaviour

- `app.py`: standalone Starlette factory/lifespan, configurable WS route,
  liveness/readiness/aggregate probes. All WebSockets are denied before upgrade.
  Readiness reports disabled signalling even if test dependencies report ready.
- `runtime.py`: per-lifespan identity, explicit starting/running/draining/stopped
  or failed phases, bounded cooperative startup/shutdown, drain-before-close,
  cleanup on failed startup, and shared shielded cleanup under repeated caller
  cancellation. Identity is diagnostic, not a distributed ownership fence.
- `config.py`: typed immutable settings, limits/route collisions/timeouts checked
  at startup, unknown configuration rejected. No Django imports or dotenv magic.
- `__main__.py`: module/console entrypoint, fixed server frame/queue limits,
  compression disabled, proxy headers disabled and safe server logging.
- `logging.py`: allowlisted JSON events; no raw log messages, URL/query data,
  arguments or exception text. This also prevents Uvicorn's denied-WebSocket
  error logger from leaking query credentials despite access logging being off.
- Dockerfile/Compose: non-root, localhost development binding, read-only runtime
  and capability drops. Optional source mount requires a process restart.
- CI: pinned action commits, locked dependencies, Python 3.12/3.13/3.14 checks,
  package build and container startup/config/probe smoke. No deployment job.

ScaffoldRuntime has no external I/O and reports Janus, Broka, authority and
ownership as not_configured. This is not a Janus simulator or a successful
integration claim. There is no setting that enables media prematurely.
