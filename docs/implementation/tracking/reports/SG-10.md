## Delivery and failure semantics

- SQLite FULL commits run serially off-loop. One persistent row reserves terminal
  capacity for each connection: 1,024 rows, 4 KiB payloads, 8,192-page database
  limit. Excess new connections reject; existing pending/live rows are not evicted.
- Intermediate states coalesce into complete snapshots. These are observations,
  not a transition audit log, permission commands or live browser notifications.
- Retries preserve event IDs, and late publication ACK cannot clear newer state.
  Every five minutes retained snapshots replay to repair dropped final entries;
  delivered terminal rows expire after 24 hours. Pending rows never expire.
- Restart turns previously live rows into terminal recovery-failed snapshots before
  replay. It never adopts old handles. Socket cancellation after commit retains
  sequence; cancellation during hello writes the otherwise-orphaned offline state.
- Online observations require a current unreleased owner lease. Matching terminal
  replay can finish after lease expiry/release. An observation consumer still
  needs current authority checks when later exposing public presence.
- Django retains at most 256 receipt samples per participant and 1,000 poison
  digests; the latest observation keeps the replay cursor after receipt pruning.
  Storage failure stops new gateway work. Broker degradation is visible in health.

## Rollback and remaining scope

keys for replay, and stop the separate Django consumer. Keep migration/inbox data.
Legacy, command and raw Janus paths remain available. Both repositories' code is
on their existing feature branches; no release, merge, deployment or production
routing changed.

The finite spool/retention budget needs production sizing and durable storage;
loss of the disk or broker history beyond the retained snapshots requires operator
reconciliation. This is not zero-loss transition auditing. Permission-aware public
presence/SSE is SG-11; frontend routing is SG-12; physical moderation is SG-13;
resume/failover is SG-14/15; load and rollout gates remain SG-16–18. No additional
